## 1. 테스트 범위·제외

| 구분 | 내용 |
|---|---|
| A. 현행(AS-IS) 확인 | 현행분석서의 기능·제약 기술이 실제 동작과 같은지 확인한다. **판정 기준은 "올바른 동작인가"가 아니라 "01 문서의 기술과 일치하는가"다.** 결함을 재현한 TC가 PASS면 그 결함이 실제로 있다는 뜻이다 |
| B. 이관(TO-BE) 검증 | 요구사항정의서의 RQ를 검증한다. 이관 구현 전이라 **전부 미실행**이며, 이관 단계에서 자동화 테스트로 옮겨 실행한다 |
| 제외 | 화면 배치·문구·브라우저 호환성, 다국어(AS-F-082), 부하·성능(이관 후 측정 문서에서 다룸), 첨부 이미지 표시, 쿠키 만료 동작 |

시험 계정은 실행 중 회원가입으로 만든다(`tester_a`, `tester_b`, `admin`). 시드 데이터는 상품 1건, 콘텐츠 6건뿐이다.
